# Original Project

## Purpose

The original quantitative-analysis final project explored temporal patterns in reported UFO sightings and possible state-level associations with military-base and nuclear-facility counts.

## Original Automated Workflow

The project included three scripted stages:

1. Clean and prepare tens of thousands of report records.
2. Generate exploratory statistics and figures.
3. Run hypothesis tests, correlations, and multiple regression.

The work demonstrated practical use of Python data processing, temporal feature engineering, visualization, inferential statistics, and automated reporting.

## What Is Preserved Here

This repository preserves the research questions, workflow lineage, analytical components, and engineering achievement. It does not redistribute the original raw dataset, witness narratives, course submission documents, or personal execution logs.

The military-base and nuclear-facility questions are preserved as historical research questions, not as validated findings in the current release.
