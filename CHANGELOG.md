# Changelog

## 1.0.0 — 2026-07-12

First public release.

- Rebuilt the original quantitative-analysis workflow as a reusable Python package.
- Added a deterministic 5,000-record synthetic demonstration generated inside the selected output directory.
- Added human-readable validation, optional JSON output, and a safe CSV template command.
- Added quality flags, sample-flow accounting, structured reports, and six accessible SVG figures.
- Corrected calendar-date handling, complete monthly sequences, zero-report-month retention, and analysis-specific exclusion logic.
- Added graceful descriptive-only behavior for sparse datasets and actionable blocking errors for empty datasets.
- Added consistent synthetic versus user-supplied labels across every output layer.
- Added a transparent project-evolution and methodology-audit case study.
- Added automated tests, multi-platform CI smoke tests, Codespaces support, generic privacy scanning, and release-manifest tooling.
- Removed third-party raw data, witness narratives, original course files, personal logs, embedded private denylist terms, and unnecessary biography.
