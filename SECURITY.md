# Security and Data Safety

Report software vulnerabilities through the repository's private vulnerability-reporting form:

<https://github.com/LuckyGitHub777/ufo-uap-sightings-analysis/security/advisories/new>

Do not disclose vulnerability details in a public issue or pull request. Do not submit real personal data, credentials, private infrastructure details, witness narratives, or restricted datasets.

The analytical application operates offline and makes no network requests. GitHub-hosted development, Actions, and Codespaces naturally use GitHub infrastructure.

If the private form is unavailable, do not post the details publicly. The repository owner must enable private vulnerability reporting before accepting a security report.
